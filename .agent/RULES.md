Code Style & Formatting\n\nQuy tắc về style code và formatting:\n\n### 1.1. General\n- **Language**: TypeScript (Strict Mode)\n- **Indentation**: 2 spaces (NOT tabs)\n- **Line Length**: Max 120 characters\n- **Quotes**: Single quotes for strings (except template literals)\n- **Semicolons**: Always required\n- **Trailing Commas**: Always in multiline\n- **Formatter**: Prettier (auto-format on save)\n- **Linter**: ESLint (auto-fix on save)\n\n### 1.2. File Organization\n```typescript\n// 1. Imports (sorted alphabetically)\nimport { Component } from '@angular/core';\nimport { Observable } from 'rxjs';\n\n// 2. Interfaces/Types\ninterface IUser {\n  id: string;\n  name: string;\n}\n\n// 3. Component/Class Declaration\n@Component({\n  selector: 'app-user-list',\n  templateUrl: './user-list.component.html',\n  styleUrls: ['./user-list.component.scss']\n})\nexport class UserListComponent {\n  // 4. Properties\n  @Input() users: IUser[] = [];\n  @Output() userSelected = new EventEmitter<IUser>();\n  \n  // 5. Constructor\n  constructor(private service: UserService) {}\n  \n  // 6. Lifecycle Hooks\n  ngOnInit() {}\n  ngOnDestroy() {}\n  \n  // 7. Public Methods\n  onSelect(user: IUser) {}\n  \n  // 8. Private Methods\n  private handleError() {}\n}\n```\n\n## 2. Naming Conventions\n\nQuy tắc đặt tên:\n\n### 2.1. Files & Folders\n- **Folders**: `kebab-case` (ví dụ: `user-management`, `shared-components`)\n- **Components**: `[name].component.ts` (ví dụ: `user-list.component.ts`)\n- **Services**: `[name].service.ts` (ví dụ: `user.service.ts`)\n- **Modules**: `[name].module.ts` (ví dụ: `users.module.ts`)\n- **Pipes**: `[name].pipe.ts` (ví dụ: `safe-html.pipe.ts`)\n- **Directives**: `[name].directive.ts` (ví dụ: `highlight.directive.ts`)\n- **Models/Interfaces**: `[name].model.ts` (ví dụ: `user.model.ts`)\n- **Guards**: `[name].guard.ts` (ví dụ: `auth.guard.ts`)\n- **Interceptors**: `[name].interceptor.ts` (ví dụ: `error.interceptor.ts`)\n- **Tests**: `[name].spec.ts` (ví dụ: `user.service.spec.ts`)\n\n### 2.2. Code Elements\n- **Classes**: `PascalCase` (ví dụ: `UserService`, `UserListComponent`)\n- **Interfaces**: `PascalCase` với tiền tố `I` (ví dụ: `IUser`, `IProduct`)\n- **Types**: `PascalCase` (ví dụ: `UserType`, `ProductType`)\n- **Variables**: `camelCase` (ví dụ: `userName`, `isLoggedIn`)\n- **Constants**: `UPPER_SNAKE_CASE` (ví dụ: `MAX_RETRY_COUNT`, `API_BASE_URL`)\n- **Observables**: `camelCase` với hậu tố `$` (ví dụ: `users$`, `isLoading$`)\n- **Private Properties**: `camelCase` với tiền tố `_` (ví dụ: `_destroy$`, `_cache`)\n- **Methods**: `camelCase` (ví dụ: `getUserData()`, `handleError()`)\n- **Getters/Setters**: `camelCase` (ví dụ: `get userName()`, `set userName()`)\n\n## 3. Component Rules\n\nQuy tắc cụ thể cho components:\n\n### 3.1. Smart Components (Page/Container Components)\n- **Location**: Trong thư mục `pages/`\n- **Naming**: `[feature]-page.component.ts` (ví dụ: `user-list-page.component.ts`)\n- **Responsibilities**:\n  - Gọi services để lấy dữ liệu\n  - Quản lý state của trang\n  - Truyền dữ liệu xuống dumb components\n  - Lắng nghe events từ dumb components\n- **Change Detection**: Không cần OnPush (mặc định)\n- **Template**: Chỉ chứa dumb components, không HTML phức tạp\n\n**Template**:\n```typescript\n@Component({\n  selector: 'app-user-list-page',\n  template: `\n    <app-user-list\n      [users]=\"users$ | async\"\n      (userSelected)=\"onUserSelected($event)\"\n    ></app-user-list>\n  `\n})\nexport class UserListPageComponent implements OnInit {\n  users$ = this.service.getUsers();\n  \n  constructor(private service: UserService) {}\n  \n  onUserSelected(user: IUser) {\n    // Handle selection\n  }\n}\n```\n\n### 3.2. Dumb Components (Presentational Components)\n- **Location**: Trong thư mục `components/`\n- **Naming**: `[name].component.ts` (ví dụ: `user-list.component.ts`)\n- **Responsibilities**:\n  - Nhận dữ liệu qua @Input()\n  - Phát events qua @Output()\n  - Hiển thị UI\n- **Change Detection**: BẮT BUỘC sử dụng `ChangeDetectionStrategy.OnPush`\n- **Services**: KHÔNG được inject services (trừ các service thuần UI)\n- **API Calls**: KHÔNG được gọi API trực tiếp\n\n**Template**:\n```typescript\nimport { ChangeDetectionStrategy } from '@angular/core';\n\n@Component({\n  selector: 'app-user-list',\n  templateUrl: './user-list.component.html',\n  styleUrls: ['./user-list.component.scss'],\n  changeDetection: ChangeDetectionStrategy.OnPush\n})\nexport class UserListComponent {\n  @Input() users: IUser[] = [];\n  @Output() userSelected = new EventEmitter<IUser>();\n  \n  onSelect(user: IUser) {\n    this.userSelected.emit(user);\n  }\n}\n```\n\n### 3.3. Component Size\n- **Max Lines**: 300 dòng code (TypeScript)\n- **Max Methods**: 10 public methods\n- **Max Properties**: 10 properties\n- **Nếu vượt quá**: Tách thành các components nhỏ hơn hoặc chuyển logic vào services\n\n### 3.4. Component Lifecycle\n- **Implement Interface**: Luôn implement interface tương ứng (ví dụ: `implements OnInit, OnDestroy`)\n- **ngOnInit**: Khởi tạo, lấy dữ liệu\n- **ngOnDestroy**: Cleanup, unsubscribe từ observables\n- **Không sử dụng**: `ngAfterViewInit` trừ khi thực sự cần thiết\n\n## 4. RxJS & Reactive Programming\n\nQuy tắc sử dụng RxJS:\n\n### 4.1. Unsubscribe Pattern\n**BẮT BUỘC** unsubscribe từ observables:\n\n```typescript\nprivate destroy$ = new Subject<void>();\n\nngOnInit() {\n  this.service.getData()\n    .pipe(takeUntil(this.destroy$))\n    .subscribe(data => this.data = data);\n}\n\nngOnDestroy() {\n  this.destroy$.next();\n  this.destroy$.complete();\n}\n```\n\n### 4.2. Async Pipe\n**Ưu tiên** sử dụng async pipe trong template:\n\n```html\n<!-- ✅ ĐÚNG -->\n<div *ngFor=\"let user of users$ | async\">{{ user.name }}</div>\n\n<!-- ❌ SAI -->\n<div *ngFor=\"let user of users\">{{ user.name }}</div>\n```\n\n### 4.3. Observable Naming\n- **Tên Observable**: Luôn kết thúc bằng `$` (ví dụ: `users$`, `isLoading$`)\n- **Không lưu trữ**: Không gán observable vào biến thường (ví dụ: `this.users = ...`)\n\n### 4.4. Operators\n- **map**: Transform dữ liệu\n- **filter**: Lọc dữ liệu\n- **switchMap**: Chuyển sang observable mới (dùng cho HTTP calls)\n- **mergeMap**: Merge multiple observables\n- **takeUntil**: Unsubscribe khi component destroy\n- **debounceTime**: Delay trước khi emit\n- **distinctUntilChanged**: Chỉ emit khi giá trị thay đổi\n\n## 5. Services\n\nQuy tắc cho services:\n\n### 5.1. Service Structure\n```typescript\n@Injectable({ providedIn: 'root' })\nexport class UserService {\n  private apiUrl = '/api/v1/users';\n  \n  constructor(private http: HttpClient) {}\n  \n  // Public methods\n  getUsers(): Observable<IUser[]> {\n    return this.http.get<IUser[]>(this.apiUrl);\n  }\n  \n  getUserById(id: string): Observable<IUser> {\n    return this.http.get<IUser>(`${this.apiUrl}/${id}`);\n  }\n  \n  // Private helper methods\n  private handleError(error: any) {\n    console.error('Error:', error);\n    throw error;\n  }\n}\n```\n\n### 5.2. Service Placement\n- **Core Services**: `src/app/core/services/` (singleton services)\n- **Feature Services**: `src/app/features/[feature]/services/`\n- **Shared Services**: `src/app/shared/services/` (nếu tái sử dụng)\n\n### 5.3. Dependency Injection\n- **providedIn**: Luôn sử dụng `providedIn: 'root'` thay vì thêm vào module\n- **Constructor**: Inject dependencies qua constructor\n\n## 6. Error Handling\n\nQuy tắc xử lý lỗi:\n\n### 6.1. HTTP Errors\n- **Global Interceptor**: Xử lý HTTP errors trong `error.interceptor.ts`\n- **Không nuốt lỗi**: KHÔNG được có `catch` block rỗng\n- **Log Errors**: Luôn log errors cho debugging\n\n```typescript\n@Injectable()\nexport class ErrorInterceptor implements HttpInterceptor {\n  intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> {\n    return next.handle(req).pipe(\n      catchError(error => {\n        console.error('HTTP Error:', error);\n        // Handle error\n        return throwError(() => error);\n      })\n    );\n  }\n}\n```\n\n### 6.2. Component Errors\n- **Try-Catch**: Sử dụng khi cần thiết\n- **Error Messages**: Hiển thị user-friendly messages\n\n## 7. Testing\n\nQuy tắc testing:\n\n### 7.1.
